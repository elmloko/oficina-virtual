Servidores (modo infraestructura)

Para tus trabajos de infraestructura: eliges un servidor como destino. Con Claude Code el agente opera el servidor por SSH: lee solo, y todo lo fuerte te lo pregunta. Entra con tu llave SSH o, si prefieres, con la contraseña que guardes aquí. La contraseña se guarda solo en este equipo (archivo .env), nunca se envía al modelo ni se muestra de nuevo, y el agente no la ve; solo la usa la oficina para conectar. La primera conexión fija la huella del servidor y avisa si después cambia.
